# Product

## Register

brand

## Users

Prospective Upwork clients seeking AI agent engineering, multi-agent systems, and workflow automation, plus visitors evaluating Muhammad Rayandika's software engineering experience and projects.

## Product Purpose

A static GitHub Pages portfolio displaying **mrayandika** and linking to **github.com/mrayandika15**, as confirmed by the user. Introduce the person, show verifiable projects, and make it easy to start a conversation. Dedicated About, Work, Playground, and Contact pages let visitors explore beyond the home page.

## Brand Personality

Tactile, playful, curious. A personal engineering scrapbook with ruled paper, taped photos, handwritten notes, bright labels, and folder-shaped project sections. The user's September 25, 2026 screenshots explicitly replace the earlier cream-and-sage design direction.

## Anti-references

Generic dashboard layouts, decorative glass panels, corporate stock-photo claims, fabricated clients, and invented project metrics. The new references guide visual composition; their sample identity and project claims are not copied.

## Design Principles

- Make the person and their work easy to understand.
- Keep expressive presentation grounded in real identity and repository links.
- Distinguish visual experiments from shipped products.
- Make every navigation item and interactive control useful.
- Give mobile, keyboard, and reduced-motion experiences the same care.
- Keep the site static, lightweight, and straightforward to edit.

## Accessibility & Inclusion

Use readable contrast, semantic landmarks, visible focus, keyboard-operable navigation and disclosures, descriptive alternatives, and reduced-motion support. Preserve content and native navigation when JavaScript is disabled.

## Professional positioning

Lead with **AI Agent Engineer | Multi-Agent Systems & Workflow Automation**. Preserve the user's 4+ years of software engineering experience as the foundation for reliable integrations and full-stack delivery. Present AI Harness Workflows, agent orchestration, tool integration, and workflow automation as core services.

The About page includes user-supplied experience in agentic workflow engineering, Sovware, Kalbe Farma / Gaji Cermat / CPP projects, and frontend / GIS engineering. Do not invent employment dates, client results, certifications, metrics, or AI framework expertise. Public personal projects remain distinct from professional experience. Contact currently uses the configured GitHub profile; no Upwork URL has been supplied.
